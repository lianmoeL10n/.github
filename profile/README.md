### 🛠️项目介绍

社区本地化（LianmoeL10n）是一个开放贡献、开放共享的本地化项目，也就是说，任何人都可以参与我们的翻译工作，且以更宽松的协议使用我们的翻译作品。

目前，我们主要运营的项目是一些 Minecraft 模组的 英 -> 中 翻译项目。

### 🌴Minecraft 模组翻译

我们使用 Github 仓库（[minecraft-mods-L10n](https://github.com/lianmoeL10n/minecraft-mods-L10n)）存储翻译文件，并使用 Crowdin（[社区本地化 - Minecraft 模组
](https://crowdin.com/project/communityL10n-mcmods/zh-CN)）进行翻译、审阅。我们手动从模组源仓库中提取源英文文件，并通过 Crowdin 上传和更新源文件。Crowdin 上的翻译也会自动提交回 Github 仓库。当翻译工作完成后，会由社区本地化管理员手动下载翻译好的本地化文件，上传至 LianmoeL10n Github 团队下对应的模组仓库中，最后向原模组项目提交 PR。

#### 文件结构

在我们的总仓库下，有一个 SOURCE 目录，这里面存放的都是英文源文件。如果对应的模组各个游戏版本之间内容有差异，则会创建二级目录，放不同版本的翻译文件。一般来说，我们更偏向于维护最新版本的翻译

仓库下有许多以模组 modid 为名称的一级目录，这些目录存放着各个模组的中文翻译文件，可能会进行版本区分，与源文件的管理模式类似

#### 参与翻译

首先，感谢您计划参与我们的翻译工作！在参与翻译前，您最好先加入我们的 QQ 群。Minecraft 模组更新频繁，在每次翻译前可能都需要手动的更新源文件，随后您只需要在 Crowdin 平台中进行翻译即可。我们的审阅人员会进行简单的审阅，审阅通过后会进行提交工作。
